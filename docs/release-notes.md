# Eclipse Launcher release notes

## Highlights

- Android launcher for Minecraft: Java Edition 26.3+
- Bundled OpenJDK 25 runtime
- Fabric-first mod support, Modrinth content
- Touch and gamepad controls

## Requirements

- Android 8.0 (API 26) or newer
- arm64-v8a device
- A legitimate Minecraft: Java Edition account
- Approximately 1.5 GB free storage for a vanilla instance

## Install

1. Download the APK from the release assets.
2. Verify `SHA256SUMS.txt`.
3. Allow installation from your browser or file manager when prompted.

This release does not include Minecraft game files. The launcher downloads them from Mojang's official servers after you sign in.

## Known limitations

- 32-bit ABIs are not part of the first release.
- Vulkan rendering is experimental and falls back to OpenGL when unsupported.
- Forge is import-only; NeoForge and Quilt are post-v1.
