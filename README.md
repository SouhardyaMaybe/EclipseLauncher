- Eclipse Launcher runs [Minecraft: Java Edition](https://www.minecraft.net/) on Android devices.
- Eclipse Launcher aims to enhance the user experience with a redesigned interface, practical features, and a low barrier to entry — making it easier for more people to enjoy Minecraft.

<h2 align="center">Download</h2>

- Grab the latest APK from the [Releases](https://github.com/SouhardyaMaybe/EclipseLauncher/releases) page.
- Every release is built automatically by [GitHub Actions](https://github.com/SouhardyaMaybe/EclipseLauncher/actions) from the source in this repository.

<h2 align="center">Features</h2>

- [x] Redesigned Material 3 interface for improved aesthetics and usability.
- [x] Built-in file manager — no Android permission headaches.
- [x] Version management with customizable game directories, including external storage.
- [x] Streamlined GL4ES rendering, with support for renderer plugins.
- [x] Download mods, modpacks, resource packs, saves, and shader packs directly in the launcher.
- [x] Customizable virtual mouse icon and launcher background image.
- [x] Light and dark themes.
- [x] And more!
